# Intro media (optional)

Drop either file here and the intro picks it up automatically. Neither is
required — without them the intro plays with on-screen captions only.

- `intro.mp3` — narration audio. Script, timings and recording notes are in
  `docs/INTRO_SCRIPT.md`.
- `intro.mp4` — a finished video. Takes priority over the audio and plays
  full-bleed.

Nothing in the code needs changing when you add them.

- `vale.png` — artwork for Dr Vale in the chamber window. If present it is
  drawn inside the observation port instead of the built-in silhouette.
  Roughly 220×160 or any 11:8 ratio; transparent background; she should fill
  the lower-centre of the frame. Remove the file and the silhouette returns.
